Leaf Resource Notes

  • The VPC branch is the only place that creates the foundational subnet IDs later consumed by every other branch.
  • The TGW/GWLB branch owns the inspection routing layer: GWLB endpoint subnets, endpoint resources, and TGW attachment route tables.
  • The GWLB child branch splits cleanly into three concerns: load balancer service plane, autoscaled gateways, and management server.
  • The test instance module is intentionally separate from the GWLB stack and depends only on exported VPC ID and TGW subnet ID map outputs from module.lab.
